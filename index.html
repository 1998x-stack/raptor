CONCEPT
What is RAPTOR?
Traditional RAG retrieves only flat text chunks. RAPTOR builds a multi-layer tree where LLM-generated summaries sit above clusters of related chunks, letting retrieval operate at the right level of abstraction for each query.

Design Principles

  • Two tree strategies: classic & Psi
  • Soft clustering allows cross-cluster contribution
STRATEGY
Two Tree Builders — swap with one config field
RAPTOR offers two tree-building strategies. The classic builder iteratively clusters and summarizes each layer. The Psi builder constructs a similarity merge tree in one pass — better for very large corpora.

Usage Example
basic_usage.py
import asyncio from raptor import RAPTORConfig from raptor.builders.classic import build_tree_classic from raptor.retrieval import collapsed_tree # 1. Configure config = RAPTORConfig( max_cluster=5, tree_builder="classic", clustering_method="gmm", ) # 2. Build tree (pass your LLM & embedder as async callables) chunks = [("text...", embedding), ...] enriched, layers = await build_tree_classic( chunks, config, llm_chat_fn=your_llm_chat_fn, embed_fn=your_embed_fn, ) # 3. Retrieve results = collapsed_tree( query_embedding, layers, enriched, top_k=5, ) for idx in results: print(enriched[idx][0]) # Retrieved text
